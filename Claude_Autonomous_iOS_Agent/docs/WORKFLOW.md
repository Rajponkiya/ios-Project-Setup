# Engineering Workflow

## Understand
Read the requirement and inspect the codebase.

## Plan
Identify the smallest implementation path.

## Implement
Work in logical increments and preserve working code.

## Verify
Build and test frequently.

## Debug
Fix root causes with minimal changes.

## Review
Check correctness, architecture, memory, concurrency, error handling, and unnecessary complexity.

## Finish
Perform final build/test verification and summarize only verified results.
