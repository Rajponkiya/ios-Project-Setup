# Time-Efficient Engineering Mode

Use this mode when the delivery window is limited.

Priority:
1. Required functionality
2. Build stability
3. Critical error handling
4. Runtime correctness
5. Tests
6. Quality improvements
7. Cosmetic polish

Rules:
- Do not spend early time on animations or cosmetic refactoring.
- Build early instead of accumulating unverified changes.
- Fix blockers immediately.
- Prefer the smallest correct implementation.
- Avoid changing architecture after core implementation unless necessary.
