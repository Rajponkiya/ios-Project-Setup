# Practical Kit

Reusable Claude Code prompt kit for an iOS assignment.

## Recommended order
1. 01_START_HERE/00-master-workflow.md
2. 02_ANALYSIS/01-analyze.md
3. 02_ANALYSIS/02-plan.md
4. 03_IMPLEMENTATION/03-implement.md
5. 04_NETWORKING/04-networking.md when API work is needed
6. 05_UI/05-ui.md when UI work is needed
7. 06_BUILD_DEBUG/06-build.md after major changes
8. 06_BUILD_DEBUG/07-bug-fix.md when something fails
9. 07_TEST_REVIEW/08-test-review.md
10. 08_FINAL/09-final-review.md
11. 09_INTERVIEW/10-explain-code.md if you need to understand/explain a decision

## Important
Use only what the interviewer permits. Do not bypass restrictions on AI, internet access, dependencies, repositories, or external tools.
