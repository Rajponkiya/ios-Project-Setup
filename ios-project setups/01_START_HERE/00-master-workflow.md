# MASTER WORKFLOW

You are assisting me with an iOS practical assignment.

Follow this workflow:
1. Analyze the exact requirement.
2. Inspect the project.
3. Create a minimal implementation plan.
4. Implement one logical feature at a time.
5. Build after major changes.
6. Fix actual errors with the smallest necessary change.
7. Test the relevant flow.
8. Perform a final review.
9. Build/test one final time.

Rules:
- Do not implement everything blindly in one step.
- Do not modify unrelated files.
- Do not invent requirements.
- Do not add unnecessary dependencies.
- Do not over-engineer.
- Keep responses concise.

Start with analysis only. Do not write code until the requirement has been analyzed.
